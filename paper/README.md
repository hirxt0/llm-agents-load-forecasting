## Подготовка к подаче

Для статьи о трёх подходах нужен тест мультиагентного GPT-5 в режиме `series` на основных 200 окнах. Сохраните почасовые прогнозы, токены, число вызовов, время и признаки резервных прогнозов. Пара для сравнения — одиночный `series` на тех же окнах, отдельно по каждому набору. Перед прогоном зафиксируйте бюджет, параметры и план анализа с учётом уже просмотренных результатов одиночного агента.

Автору предобученных моделей нужно приложить почасовые прогнозы и журналы трёх прогонов. С ними можно независимо воспроизвести медианы и интервалы из приложения. Перед подачей команда также указывает авторов, организации, контактный адрес и ревизию кода и данных.
