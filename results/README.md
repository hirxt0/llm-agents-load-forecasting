## Как читать NRMSE

Для каждого окна RMSE делится на среднее потребление за 336 часов истории и умножается на 100. Чем меньше NRMSE, тем точнее прогноз. В общей таблице ошибки окон сначала усредняются внутри здания, затем берётся медиана по зданиям отдельно для каждого датасета. В парных сравнениях отношение `b/a` ниже 1 означает меньшую ошибку у метода `b`.

Имена `snaive_24` и `snaive_168` в сводке обозначают автоматически рассчитанные эталоны. Для сравнения в статье выбирайте соответствующие строки `bl_snaive_24` и `bl_snaive_168` по одному разу. Для основного сравнения используйте только методы с полным покрытием общей выборки. Строки с суффиксом `_r1` относятся к диагностической подвыборке из 50 окон.

## Какие прогоны сохранены

- `bl_*_test` и `bl_*_dev` содержат прогнозы восьми классических методов на 400 тестовых и 40 отладочных окнах. Сводка `summary_test_main_*` берёт общие 200 тестовых окон.
- `fc_gpt-5-low_*_noisy_test` содержит пять основных конфигураций одиночного агента: `no_tools`, `series`, `calendar`, `weather`, `full`. Каждая прошла 200 окон. Для конфигурации `weather` NRMSE составила 9,51% на BDG-2 и 69,92% на LCL.
- `fc_gpt-5-low_weather_noisy_masked_test` содержит прогнозы на тех же 200 окнах со скрытыми датами и названиями праздников.
- Четыре завершённых повтора `_r1` и пилоты `_dev` сохранены как дополнительные результаты. Повтор `full` остановился на HTTP 403, проба запоминания осталась без результатов. Основное сравнение опирается на один запуск каждой конфигурации.
- В этой сводке представлены классические методы и одиночный агент. Строки мультиагентной системы и foundation-моделей добавляются после получения их прогнозов на общих окнах.

В папке прогона `predictions.csv` содержит почасовые прогнозы и фактические значения. `scores.csv` содержит метрики, токены, время и сведения о сбоях по окнам агента. `run_config.json` или `run_info.json` описывает настройки, а `audit.csv` содержит результаты словарной проверки траекторий. Стоимость рассчитана по тарифу в конфигурации проекта. Фактические списания определяет провайдер API.

## Пересчёт сводки

Из корня репозитория:

```powershell
$env:PYTHONIOENCODING = 'utf-8'
python -m one_agent_forecasting.src.summarize --split test --subset main
```

Команда пересчитывает сводку по сохранённым прогнозам локально. Описание конфигураций агента и экспериментального протокола находится в [README одиночного агента](../one_agent_forecasting/README.md).
